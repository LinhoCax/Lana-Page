# LanaLinho ✦

Um projeto pessoal desenvolvido como parte do meu treinamento em desenvolvimento web, utilizando **HTML, CSS e JavaScript**.

## Sobre o projeto

O LanaLinho é um site inspirado na estética e na discografia da cantora Lana Del Rey. O projeto está sendo desenvolvido gradualmente, com o objetivo de aprender e praticar os fundamentos do desenvolvimento front-end.

A proposta é criar uma página interativa na qual o usuário possa navegar por uma página inicial e, ao clicar em um botão, selecionar uma música da cantora. A escolha deverá apresentar uma página personalizada com informações sobre a música, sua letra e um vídeo correspondente do YouTube.

## Objetivos de aprendizagem

* Compreender a estruturação de páginas com HTML.
* Aprender a estilizar elementos utilizando CSS.
* Desenvolver interatividade com JavaScript.
* Manipular elementos HTML através do DOM.
* Trabalhar com eventos e entradas do usuário.
* Aprender a organizar arquivos e conectar diferentes tecnologias.
* Praticar conceitos de responsividade e design de interfaces.

## Tecnologias utilizadas

* **HTML5** — Estrutura da página.
* **CSS3** — Estilização e identidade visual.
* **JavaScript** — Interatividade e funcionalidades.
